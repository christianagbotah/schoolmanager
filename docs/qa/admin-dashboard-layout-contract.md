# Admin Dashboard Layout Contract

The admin dashboard KPI cards must render in this fixed order:

1. Active Students · Active Teachers · Active Parents · Attendance
2. Collected for Term · Fee Arrears · Daily Revenue · Collection Rate
3. Students with Outstanding Bills · Bad Debt / Muted Students · Total Income · Total Expenses

The presentation layer must reuse the existing live CI3 values and actions rather than recalculate finance figures in JavaScript.
